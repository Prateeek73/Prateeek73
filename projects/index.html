Most of what I build is meant to be used by someone who did not write it. FragBERTa productionizes a fine-tuned 110M-parameter BERT model so researchers can screen 1k+ compounds in under 90 seconds, over FastAPI and React on HPC infrastructure. nuGAN does the same for cosmology, deployed with Flask, Gunicorn and Nginx. I also built a RAG document Q&A system over FastAPI and pgVector, with answers grounded in the source material.

On the infrastructure side, a GPU-accelerated Apache Spark pipeline hit 97.37% accuracy on 20k+ COCO images in six minutes using data parallelism. A more speculative one: a multi-agent LLM pipeline running Designite and RefactoringMiner across Apache repositories, verifying every proposed change still compiles.

Some projects answer a question rather than serve anyone. Mormon-NLT compares LoRA adapters against full fine-tuning on Qwen2.5 for Shakespearean style transfer, reaching state-of-the-art BERTScore. I am building a chess engine on a Byte Latent Transformer with no hand-crafted evaluation function. And a U-Net against a lightweight CNN for wound-area segmentation reached a 0.914 Dice score.

Older statistical work: SARIMA forecasting on PJM energy consumption; housing price prediction at R² 0.7357; Plotly visualizations of global temperature trends; and a Bayesian mixture model of plasma glucose using Gibbs sampling in JAGS.

Another thirty-odd repositories are on GitHub.
